# AgenticRL Anonymous Project Page

This is a static anonymous project page for AgenticRL.

## How to use

1. Replace placeholder links in `index.html` for paper, code, and supplementary.
2. Put videos in the `videos/` folder using these names:
   - `main_demo.mp4`
   - `trajectory_following.mp4`
   - `gate_traversal.mp4`
   - `obstacle_landing.mp4`
   - `circular_motion.mp4`
   - `reward_evolution_s1.gif`
   - `reward_evolution_s2.gif`
3. Update related-work and ablation tables in `index.html`.
4. Push to a fresh anonymous GitHub Pages repository.

## Anonymity checks

- Remove real author names, institution names, file paths, and lab references.
- Strip image/video metadata before upload.
- Use an anonymous GitHub account or anonymous mirror.
- Do not use personal YouTube/Google Drive links.
